# 🏙️ CivicLens

> 🚧 **Currently under active development.**

CivicLens is an AI-powered civic issue reporting platform designed to help citizens report public issues such as potholes, garbage, water leakage, and damaged infrastructure. The goal is to provide an efficient bridge between citizens and local authorities through a modern, intuitive, and scalable web application.

## 📌 Current Status

This project is currently being developed. New features, improvements, and documentation are being added regularly.

### Planned Features

- User Authentication
- AI-powered issue categorization
- Image upload support
- Interactive maps
- Complaint tracking
- Admin Dashboard
- Analytics & Reports
- Real-time notifications

## 🛠️ Tech Stack

### Client
- React.js
- Vite
- Tailwind CSS

### Server
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication
